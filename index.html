星际移民中心火星历

一年 24 个月，以二十四节气命名。每年从北半球春分开始，每个月的第一天都是星期日。

 

6、12、18、24 月有 27 天，其余各月 28 天，平年共 668 天。闰年在 24 月多加一天，每十年有六个闰年，平均每年 668.59 天，接近火星回归年的 668.5921 个火星日。第 1 年始于 1970 年 4 月 28 日。

火星时区

星际移民中心时间使用与地球相同长度的小时，所以一个火星日是 24 小时 39 分 35 秒。火星因此分为 25 个时区，每个时区相差一小时、宽 14.5987 经度，从艾里-0 向东计算。

时区经度（东经）比 0 区快现在时间地点

把火星时钟放到你的网站上

选好选项，复制一段代码即可。小组件在访客的浏览器里运行，托管没有任何成本。

在你的项目里使用

本页所有数据都来自一个没有任何依赖、带完整测试的 JavaScript 小文件。它以 MIT 许可证免费使用，以静态文件发布，运行没有任何成本。

在网页或 Node 中

import { marsTime, interimmTime } from
  'https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/marstime.js';

const now = marsTime(new Date(), { longitude: 137.44 });
now.mtc   // 协调火星时（小时）
now.lmst  // 盖尔撞击坑的地方平太阳时
now.ls    // 季节（度）
interimmTime(new Date(), { zone: 5 }).clock   // "06:19:12"

作为小组件

想要带样式的卡片，用上面的嵌入生成器；想要沿用你网页样式的纯文字，用 <mars-clock>：

<script type="module" src="https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/mars-clock-element.js"></script>
<mars-clock></mars-clock>  <!-- 或 show="interimm" zone="5"，show="sol" mission="perseverance" -->

光年

给邻近恒星的信什么时候到、星际航程中船上和火星上各过了多少年：见光年页面和 lib/lightyear.js。

给 AI 助手用

把火星时间工具加到 Claude、Cursor 或任何支持 MCP 的客户端，只需要 Node：

claude mcp add mars-time -- npx -y github:InterImm/mars-clock#gh-pages

# 或写进 MCP 配置文件
{ "mcpServers": { "mars-time": { "command": "npx", "args": ["-y", "github:InterImm/mars-clock#gh-pages"] } } }

# 或在命令行直接查询一次
npx -y github:InterImm/mars-clock#gh-pages now --longitude 137.44

会浏览网页的大语言模型可以从 llms.txt 开始；JSON 接口有 OpenAPI 描述。

以 JSON 形式，任何语言都能用

预先算好的数据表：2000–2050 年每天 UTC 00:00 一行，另有每个火星年和星际移民历年份的起始时间。

curl https://interimm.org/mars-clock/api/v1/daily/2026.json
curl https://interimm.org/mars-clock/api/v1/mars-years.json

所有函数和字段见接口索引和 README。

关于

火星时间按照 NASA GISS 的 Mars24 算法计算（Allison & McEwen 2000, Planet. Space Sci. 48, 215–235）。本页最初基于 James Tauber 的 Mars Clock，星际移民中心在 2016 年加入了自己的历法、计时和时区。源码在 GitHub。
