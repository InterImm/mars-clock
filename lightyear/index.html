恒星光谱型距离一问一答火星上船上

怎么算的

飞船按恒定的“体感”加速度加速（狭义相对论的双曲运动），到巡航速度后滑行，到达前用同样的加速度减速。没有设巡航速度时，飞船一直加速到中点再掉头。火星和太阳几乎静止于同一参考系，所以“火星上经过”的时间就是太阳系里的时间。恒星距离取自 SIMBAD 和 Gaia 并做了四舍五入。

星际移民中心纪年比现实日历早 70,491 天：现实的 2026 年 10 月 3 日就是故事里的 2219 年 10 月 3 日，地球化第一阶段开始的那一年。

这些计算都在一个没有依赖的 JavaScript 文件里，可以直接在你的项目中使用：

import { voyage, message } from
  'https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/lightyear.js';

voyage({ distance: 10.47, accel: 1 })   // 1 g 去天苑四
// { earthYears: 12.26, shipYears: 4.93, peakBeta: 0.988, ... }

恒星表和每种飞船的航程也有 JSON 版：stars.json。AI 助手可以用 MCP 工具 light_message 和 interstellar_voyage，见火星时钟页面。
