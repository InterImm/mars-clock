The InterImm calendar

24 months named after the Chinese solar terms. Each year starts at the northern spring equinox, and every month starts on a Sunday.

 

Months 6, 12, 18 and 24 have 27 sols, the rest 28, so a common year has 668 sols. Leap years add a 28th sol to month 24, six years in ten, giving an average of 668.59 sols, close to the 668.5921 of a Mars tropical year. Year 1 began on 28 April 1970.

Timezones

InterImm time uses Earth-length hours, so a sol has 24 hours and 39 min 35 s. That makes 25 zones, each one hour or 14.5987° of longitude wide, counted east from Airy-0.

Use it in your own project

Everything on this page comes from one small JavaScript file with no dependencies and a test suite. It is free to use (MIT licence) and costs nothing to run: it is served as static files.

In a web page or Node

import { marsTime, interimmTime } from
  'https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/marstime.js';

const now = marsTime(new Date(), { longitude: 137.44 });
now.mtc   // Coordinated Mars Time, hours
now.lmst  // local mean solar time at Gale crater
now.ls    // season, degrees
interimmTime(new Date(), { zone: 5 }).clock   // "06:19:12"

As a widget

Use the embed builder above for a styled card, or <mars-clock> for bare text that takes your page's style:

<script type="module" src="https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/mars-clock-element.js"></script>
<mars-clock></mars-clock>  <!-- or show="interimm" zone="5", show="sol" mission="perseverance" -->

For AI assistants

Add the Mars time tools to Claude, Cursor or any MCP client. Nothing to install beyond Node:

claude mcp add mars-time -- npx -y github:InterImm/mars-clock#gh-pages

# or in an MCP config file
{ "mcpServers": { "mars-time": { "command": "npx", "args": ["-y", "github:InterImm/mars-clock#gh-pages"] } } }

# or once, from any shell
npx -y github:InterImm/mars-clock#gh-pages now --longitude 137.44

Language models that browse can start from llms.txt; the JSON endpoints are described in OpenAPI.

As JSON, from any language

Precomputed tables, one row per day at 00:00 UTC for 2000–2050, plus Mars Year and InterImm year start dates.

curl https://interimm.org/mars-clock/api/v1/daily/2026.json
curl https://interimm.org/mars-clock/api/v1/mars-years.json

See the index and the README for every function and field.

About

Mars time follows NASA GISS's Mars24 algorithm (Allison & McEwen 2000, Planet. Space Sci. 48, 215–235). The page began as James Tauber's Mars Clock; InterImm added its calendar, timekeeping and timezones in 2016. Source on GitHub.
