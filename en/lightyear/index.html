How it works

The ship accelerates at a constant felt acceleration (hyperbolic motion in special relativity), coasts at its cruise speed and brakes the same way before arrival. With no cruise speed it accelerates to the midpoint and flips. Mars and the Sun share one frame closely enough that time "on Mars" is solar-system time. Star distances are rounded from SIMBAD and Gaia.

The InterImm story calendar runs 70,491 days ahead of the real one: 3 October 2026 is 3 October 2219 in the story, the first year of terraforming phase 1.

All of it is one JavaScript file with no dependencies that you can use in your own project:

import { voyage, message } from
  'https://cdn.jsdelivr.net/gh/InterImm/mars-clock@gh-pages/lib/lightyear.js';

voyage({ distance: 10.47, accel: 1 })   // 1 g to Epsilon Eridani
// { earthYears: 12.26, shipYears: 4.93, peakBeta: 0.988, ... }

The star table with trip times for each ship is also JSON: stars.json. AI assistants can use the MCP tools light_message and interstellar_voyage; see the Mars Clock page.
